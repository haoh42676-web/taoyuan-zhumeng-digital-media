# 小桃满对话与移动浏览适配

适用数字媒体赛副本，2026-10-23。

客服允许自然问候、感谢、模糊澄清和连续追问；围绕选桃、保存、IP创作、调研、推广与合作提供公开建议。混合问题回答项目相关部分，明确无关任务和索取私密资料仍会拒绝。商品提及以当前公开商品的唯一名称、ID或规格别名解析，多款匹配时不猜测。

服务端按登录会话保存有限主题、商品ID及回答类别，30分钟过期；不保存原始对话到上下文，不把用户原文或私人资料交给外部模型。问候、澄清和规则建议可直接本地回答。静态站懒加载同一公开分类模块，仅在本页保留有限上下文，不调用外部模型或生产API。

弹窗打开聚焦关闭控件，避免提前唤起软键盘；输入字号至少16px。共享UI根据可视视口调整正在编辑的弹窗，包含安全区、横竖屏、分屏和传统vh回退。聊天仅消息区域滚动，背景锁定并在关闭后还原位置。输入聚焦时保持按钮在按下与点击间的位置，修复Firefox/WebKit关闭和发送首击丢失。后台长表单保持关闭控件可达。

存储被禁用、数据损坏或写入配额不足时，静态体验降级到本页内存并显示提示。为剪贴板、订单去重ID、媒体查询监听及部分较新JavaScript接口提供回退。网络请求包含响应体读取超时；仅只读请求可重试，提交不自动重试。

验证使用本地隔离数据库和规则客服，不调用真实模型。浏览器矩阵覆盖Chrome、Edge、Firefox、WebKit以及320—1440px视口；另外检查模拟键盘缩高、横竖屏、分屏、静态客服、后台编辑和正常业务路径。Windows浏览器引擎与视口测试不等于实体iPhone/iPad及系统软键盘测试。

本地检查报告在 `test-results/mobile-chat`、`test-results/digital-focus` 和 `test-results/review-static-chat`，这些目录不发布。凭据、备份和部署配置位于私有目录，不进入公开源码或静态快照。
