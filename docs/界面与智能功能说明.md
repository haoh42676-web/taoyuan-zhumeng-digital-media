# 界面与智能功能说明

## 1. 从哪里开始

- 前台提供明显的“小桃满客服”入口，点击打开对话框。查看商品、批次事实、收货售后说明不需要调用模型。
- 客服对话需先注册或登录。普通客户账号只管理本人的客服记录，不能进入正式运营后台。
- 公共测试账号为 test1。它用于演示体验，不获得正式后台权限，也不消耗外部模型额度。正式后台使用该账号登录时，会自动进入隔离的模拟工作区。
- 模拟工作区各业务类别提供模拟数据，并明确标识“模拟”。测试操作不会写入正式经营数据。

## 2. 客服能回答什么

客服覆盖整个项目：商品规格、参考价和计价说明、当批配送、本人原浏览器提交记录对应的有限物流状态、售后登记，以及项目调研、IP营销、青年协作、AI+OPC、赛事讲解、合作和农文旅公开信息。完全无关的问题会被拒绝。客服不代替运营确认库存、运费、到货时间或赔付，不收款、不修改订单、不执行退款。

知识来自已发布的商品、批次、FAQ与脱敏公开项目知识包。内部资料档案、未发布草稿、管理员数据和私有原件不会直接变成客服知识。没有依据时说明限制；不会把调查、预算、方案或模拟数据当作经营成果。

正式客服与后台商品文案已接入项目主模型。主接口六秒内未完成、报错或未通过事实检查时取消并尝试DeepSeek备用，再失败则使用规则。当前主模型已实际验证可用；现有DeepSeek凭据验证返回401，因此不能宣称备用已接通。公共测试账号始终使用规则，不消耗外部模型。GLM暂不接入。

外部模型仅获得固定意图标签与相关公开脱敏事实，不发送原始用户问题、订单、物流、私有资料或原始商品描述。输出依据由服务端核对，不依赖模型自行遵守提示词。

## 3. 资料批量上传

在后台“资料导入与归档”中，按以下顺序操作：

1. 选择“批量上传”，可同时选择文档与影像。支持PDF、DOCX、TXT、MD、CSV、JSON、JPG、PNG、WebP；每批最多10份，每份不超过8MB，合计不超过24MB。
2. 服务在本地提取可读取文字并按关键词建议类别；扫描文档和图片不做OCR，需手动填写事实或画面说明。
3. 展开确认清单，核对标题、分类、正文、来源、使用状态和目标栏目。自动脱敏只识别常见格式，仍需人工检查姓名、位置、肖像、二维码、手写信息与使用授权。
4. 逐项确认事实、脱敏和权利后，保存为草稿。每份资料保留项目资料档案；选择IP栏目、商品、批次等目标时，额外创建相应栏目草稿。
5. 前往对应栏目复核并执行原有发布流程。上传、分类和保存草稿都不会自动公开，不会自动生成真实订单、库存或“已核验”状态。

用户已决定暂不接入GLM；当前只保留接口，不进行账号注册或密钥申请。界面在未配置时明确显示本地规则与手工分类，外部AI选项不可用。未来启用时，应另行确认授权，只向服务端配置的模型发送经脱敏、限长的文字片段。

## 4. 不使用AI也能录入

- **AI OPC与运营/IP资料：** 选择“手工录入”，填写事实、来源和使用限制，可同时整理为IP栏目草稿。
- **核验码与批次事实：** 手动填写核验码、批次编号及事实字段。核验码用于定位记录，填写码不代表已经核验，仍须完成实际事实检查。
- **影像证据：** 可手工填写画面说明；上传图片时关闭AI选项即可保留私有影像。需要对外使用的图片，应另行在素材库核对授权与隐私后上传。

待确认原件保留60分钟；确认后原件和档案私有保留。业务备份包含已确认原件，不包含尚未确认的临时上传。私有原件不生成公开图片地址。

## 5. 额度、安全与数据口径

客服采用登录会话、独立操作凭据、来源检查、账户并发限制及账户/IP/全站配额。账户默认每分钟5次；普通账号每天40次，公共测试账号每天10次。实际还受服务配置与可用预算限制；这些措施降低盗用与滥用风险，不等同于绝对无法被代理。

规则回答和模型回退同样消耗账户请求额度，避免反复请求绕过限制。公共测试账号强制使用规则模式。密钥只放在服务端环境配置，不写入页面、仓库或客服回复。日志与对话遵循有限保留和访问权限；客户可清除本人的客服对话记录。

正式销售、库存、访客和财务指标按各自实际记录统计。AI看板无签收订单时默认提供明确标记的内存模拟视图，可切回真实空状态；不把示例写入正式业务表。完整可操作样本放在隔离模拟区或静态浏览器沙盒，不能据此宣称业绩。

## 6. 静态备份与正式服务

静态网站没有服务端和私有数据库，只能进行浏览器内的本地模拟、规则回答和演示交互。它不能安全保管模型密钥、不能调用私有后台接口，也不代表订单、上传或账号已写入正式服务。需要真实持久保存、权限管理与后台审核时，使用部署了服务端的正式网站。
