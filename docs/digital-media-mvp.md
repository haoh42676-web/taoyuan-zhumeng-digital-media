# 数字媒体赛 MVP 改造说明

前台保留四个入口：

| 页面 | 用户能完成的事 | 管理入口 |
|---|---|---|
| 首页 | 认识桃乡、查看少量商品、进入选购与招募 | 网站设置、商品与订单 |
| 桃乡见闻 | 按桃园、采摘、装箱、市集、果实分类看实拍，打开照片详情 | 照片与内容 |
| 买桃下单 | 查看规格与批次规则、核对到手价、提交订单、查看本人订单、取消未付款订单、反馈售后 | 商品与订单 |
| 加入我们 | 报名、查看审核结果、完成培训、领取自己的任务、提交成果、查看反馈、生成文字草稿 | 推广成员 |

后台日常导航为工作概览、商品与订单、照片与内容、推广成员、网站设置。调研档案、历史台账、访问统计、备份等保留在二级工具；前台不加载问卷全量数据，不显示赛事讲解、开发接口目录和旅游预约。

## 业务流程

订单由服务器按商品版本、单价、数量与每单配送费重新计算金额。提交不等于付款；未付款保留真实库存24小时，取消或超期释放。收款登记核对金额及凭据，发货须登记快递和运单，模拟流程不减少真实库存或计入真实收款。售后反馈绑定本人订单，后台回复后本人可见。

商品缺少当前核验依据时只开放模拟选购。模拟收件信息使用固定样例，不收款、不发货；实际销售需管理员核实产地、等级、批次、价格、库存、配送区域和售后条件。尚未接入支付和快递实时轨迹服务。

报名由唯一管理员审核。通过后进入成员工作台，完成全部课程测验才能派发和提交任务。成员只可读取自己的培训、任务和审核结果，不能访问顾客资料或获得后台角色。课程更改后对应完成记录失效。脚本助手输出可编辑文字，不生成视频成片，不自动发布或结算。

## 照片与 IP

从团队素材库挑选15张实拍，提供640及1280/1600宽度版本，共约2MB。保留色彩、人物原貌，移除图像定位元数据。素材来源和原始文件路径仅在私有记录中保存。图片为既有实践记录，不能作为当前在售批次的证明。

小桃满用于产地引导、礼赠说明、选购咨询与培训提示，真实影像和当批商品事实提供依据。照片说明、展示顺序、商品规则、课程和网站说明通过管理员维护。

## 技术与数据边界

前台使用原生 JavaScript/CSS；管理端复用既有管理框架。Express提供带会话、CSRF与权限校验的JSON接口，Neon保存独立项目数据，Render运行独立服务。新增数据表为 digital_settings、digital_products、digital_orders、digital_applications、digital_training、digital_tasks。

客服读取当前数字媒体商品信息。顾客物流问题只返回本人订单的脱敏进度；收件资料不发送给模型。公开体验按浏览器隔离，使用固定样例。后台下载的私密恢复备份含收货资料和顾客密码哈希，不含明文密码、管理员凭据、API密钥、会话或聊天内容，须离线妥善保管。

GitHub Pages为独立静态备份。其表单与管理操作仅在当前浏览器模拟，不访问正式数据库；体验记录与在线服务分开。所有平台保持现有免费配置，不添加保活或自动轮询访问。
