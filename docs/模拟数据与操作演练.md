# 模拟数据与操作演练

本次补充只用于演示。模拟数据不代表团队销量、真实客户、实际库存、劳动结算、调研结论或合作成果。

## 三种数据环境

- 正式后台：实际记录保持原状，不向正式业务表补入虚构订单、客户或库存。没有签收订单时，AI看板默认显示醒目标记的内存示例，可切回真实记录。示例不会写入数据库。
- 隔离演示后台：公开体验账号进入 /demo/admin/，数据库位于独立 peach_demo schema。模拟资料与正式经营隔离；仍执行相同字段、金额、关联和状态校验。
- GitHub Pages：静态演示记录只保存在当前浏览器，不调用模型或写入正式数据库。

## 补充场景

1. 商品批次：家庭装、尝鲜装、礼盒和团购；正常、低库存、售罄和待核验状态。核验状态只是隔离场景里的流程演练。
2. 订单履约：待核对、成交核实、已发货、已签收、已取消；模拟部分退款、全额退款、渠道与省级地区。
3. 客户售后：匿名代号、服务回访、独立营销授权示例；咨询、破损、规格疑问、走访意向。无真实电话、地址、证件或运单。
4. IP与青年协作：小桃满事实说明卡、文案前后对照；待培训、派发、提交、退回、验收及模拟结算。
5. 经营复盘：待判断、采用、拒绝、执行、复盘；计划、进行中和完成的版本对照。合成A/B人数只演示计算，不证明效果。
6. 资料档案：IP、合作、调查引用、赛事讲解的合成模板，仅草稿。已有真实调研数字和项目证据不会被示例替换。

## 统计与更新

- 销售图表按模拟订单计算，只有签收完成进入签收收入；退款单独扣减，取消订单不能变成销量。
- 库存扣除已确认、已发货、已签收的数量；待核验批次显示未知，不能当作零库存。
- 示例日期只是用于演示近期图表，不表示真实当季采摘或供应。
- 服务启动及每小时检查演示日期；只更新未被人工编辑的预设样本。版本与内容签名共同保护已编辑样本。
- 新示例按稳定编号增量加入，重复运行不会生成重复订单或覆盖人工修改。
